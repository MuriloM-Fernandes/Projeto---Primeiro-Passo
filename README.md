# PrimeiroPasso 🚀

> Ajudando jovens a conquistar a primeira oportunidade no mercado de trabalho.

A aplicação web **PrimeiroPasso** tem como foco principal ajudar jovens que procuram a **primeira oportunidade no mercado de trabalho**.

É um site **100% responsivo**, focado na Experiência do Usuário (UX), facilitando a interação e a navegação em qualquer dispositivo.

### 🔗 Demo do projeto
[Ver protótipo no Figma](https://www.figma.com/design/FmiVYQy7rbQvSpWN5GBqaK/Primeiro-Passo?m=auto&t=ag1wCWexgrlHBkbT-6)

### ✨ Funcionalidades
- 📱 **Layout Responsivo** - Celular, Tablet, Desktop e Notebook
- 👤 **Login Usuários**
- 🏢 **Login Empresas**
- 📝 **Criar conta**
- 🔍 **Visualizar vagas + Filtro de vagas**

### 🛠️ Tecnologias
- **HTML5** - Semântico
- **CSS3** - Flexbox, Grid, Animações
- **JavaScript** - Interatividade

### ▶️ Como rodar o projeto
1. Baixe o projeto
2. Abra o arquivo `index.html` no navegador
Pronto!
